# Vision

Filyy is a file manager for one person on a tiling Wayland desktop (Hyprland): fast from the keyboard, calm to
look at, and safe with files.

Better than the file manager it replaces means, concretely:

- Every action is reachable from the keyboard, and the common ones by one key (Space, F2, Del, Ctrl+K).
- Nothing is lost by accident: copies and moves ask about conflicts, deletes go to the trash, and the last file
  action can be undone.
- It looks like the owner's other apps (Calendary, Fold, Rewa, Leech): grey surfaces, no chrome, quiet motion.
- It stays small: Python and Qt Quick, no framework beyond PySide6.
